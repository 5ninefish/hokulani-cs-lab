Station 212 min

🧭 Algorithms

An algorithm is a step-by-step list of instructions for finishing a task. A recipe is an algorithm. A dishwasher cycle is an algorithm. Native Hawaiian weavers followed an algorithm when they made a sail or a mat — no computer required.

Algorithm — the list of steps. Even a wrong list is still an algorithm; it just is not the one you wanted.

Program — that same list written so a machine can run it. Coding is writing the algorithm for a machine.

Station 315 min

🧩 Sequence, loop, conditional, program

Read the four ideas first. Then tag each everyday example. (The lauhala rose comes in the next station.)

Sequence

1. Shoes on→2. Walk out→3. Done

A series of actions in a specific order. Action 1, then Action 2, then Action 3, until the list is done. Never the reverse. A list in the wrong order is still a sequence; it is just not the sequence you wanted.

Loop

fold→roll
until thick

A set of steps you repeat until a stopping point. Stir, stir, stir until the sauce is thick. Sleep, wake, sleep, wake every day. The repeat is the loop.

Conditional

If raining?→Yes: umbrella→No: leave it

An if/then (and often else) choice. The next step depends on a condition being true or false.

Program

recipe on paper→run on a machine

An algorithm written so a machine can run it. A recipe on paper is an algorithm. That recipe typed so a robot or this page’s artist can follow it is a program.

Station 418 min

🌺 The lauhala rose

Lauhala is the dried leaf of the hala (pandanus) tree. Hawaiian weavers used it for mats, baskets, and sails because it can get wet and keep its shape. Kapa (bark cloth) tears when wet, so it would make a poor sail. The weavers chose the material, then followed steps.

A lauhala rose is a small coiled flower made from a strip of that leaf. You hold one strip as a base, fold another strip over it, and roll. You keep folding and rolling. The coil grows into a tight blossom — like wrapping a ribbon into a rose. If the working strip gets short, you add another strip and keep going. When the coil is the size you want, you finish and secure it.

This lab is virtual. You do not need real leaves. Look at the photos, then put the mixed-up direction cards in order.

1. Base

Hold one dried strip flat. This is the core the coil wraps around.

2–3. Fold and roll

Fold a working strip over the base and roll. Repeat. That repeat is a loop.

4. Rose

Keep looping until the coil is thick enough, then finish and secure.

Tap cards into order

The cards in the pool are mixed. Tap them in the order you think is correct. Each card is one event. Putting them in order makes a sequence — the algorithm for the rose.

🔁 Name the parts

You just ordered the rose algorithm. Now map each piece to the four ideas:

  • The whole ordered list is the algorithm.
  • Repeated fold-and-roll is a loop — you do it until the rose is thick enough.
  • “If about four inches of strip remain, add a new strip; else keep weaving” is a conditional.
  • When those steps are written so this page’s artist can run them, that list becomes a program.

How to build it

  1. In Editing screen, leave it on 1.
  2. Type a Title (at least two letters) and a short Body.
  3. Type Button A label (the words on the button, e.g. “Next”). Under Button A goes to, pick Screen 2.
  4. Change Editing screen to 2. The boxes clear for screen 2 — that is normal. Fill title, body, and Button A (send it to Screen 3).
  5. Change Editing screen to 3. Fill title, body, and Button A (send it back to Screen 1, or to Screen 2).
  6. Button B is optional. Use it for a “Back” button if you want two ways to move.
  7. Watch Preview as you type. Tap the preview buttons to walk through the app like a student would.
  8. Tap Check my app when you think it is done.

Done when

Every screen has a title. Every screen has Button A. Those buttons reach at least two different screens (so the app actually moves). Then tap Finish station.
